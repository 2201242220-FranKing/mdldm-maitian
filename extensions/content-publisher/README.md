# 内容工作台发布助手（本地版）

基于麦田发布助手商店版 0.5.1 的 Apache-2.0 代码修改。原 LICENSE 保留。
2026-11-23 修改：新增小红书图文入口、图片目录识别、文案编辑、图片预览排序、
工程保存备份、校验和图文填写适配。原视频分发与 X 长文保留。

## 安装

1. Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 点“加载已解压的扩展程序”，选择本目录。
3. 在工具栏打开“内容工作台发布助手（本地版）”。
4. 商店版不用卸载；可暂时关闭，避免打开错误侧栏。

本地版使用独立扩展 ID，不继承商店版的目录授权和本机路径。
首次需重新选择发布目录、授权并填写该目录在本机的绝对路径。
不要复制商店版的 key、update_url 或 `_metadata`。

## 图文

切到“小红书图文”，选择发布根目录。识别以下工程：

- `publish.json` 中 `mediaType: "images"`，图片路径按 `images` 数组顺序。
- 尚无 JSON，但目录直接含 PNG/JPEG/WebP 图片，或有 `图片/` 子目录。

选择工程，填写标题、正文和话题，调整图片顺序后“保存图文工程”。
新工程只写入所选图片目录；已有 JSON 修改前会确认，并新建时间戳备份。
只保存不上传。点“一键填写所选平台”并确认后才开始上传。
最终发布始终由用户自己点击。不要在已有草稿上盲目重试。

图文仅接小红书，1–18张、单张20MB是本工具限制，不是官方上限。
0.5.4 起，`archive.mode: "archive_only"` 存档逐篇只读展示，展开可查看各平台状态。
已发布仅依据对应平台的发布元数据或明确的已发布 skip；普通 skip 不等于已发布，
没有记录的平台显示“未登记发布”，不能从 X 已发布推断其他平台也已发布。
存档不可直接填写；跨平台需单独准备本平台文案与图片或成片。
非存档 X 长文不混入视频、图文可填写列表。
旧 JSON 未声明 `mediaType` 时，按 `video` 路径或小红书 `images` 列表识别。
网页和命令行仍独立于此侧栏；安装本地插件不会自动更改中控配置。

平台图文 DOM 尚需首次真实使用验收。数量、正文或话题回读不符会停止，
不会自动点击发布。
